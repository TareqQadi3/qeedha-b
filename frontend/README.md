# Qeedha Accounting - Frontend (Phase 2)

واجهة React + Vite + TypeScript + Tailwind (RTL) متصلة فعليًا بواجهات المرحلة
الثانية الخلفية (Products, Catalog, Inventory, Customers, Suppliers). لا
بيانات وهمية - كل شاشة تستدعي الـ API الحقيقي.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # عدّل VITE_API_BASE_URL إذا لزم
npm run dev
```

يفترض تشغيل الـ backend على `http://localhost:3000` (راجع `../backend/README.md`).

## النطاق الحالي (Phase 2)

- تسجيل الدخول (بما فيه اختيار المنشأة لمن لديه أكثر من عضوية) + تسجيل منشأة جديدة.
- المنتجات: بحث، صفحات، إضافة (مع تصنيف/علامة/وحدة/باركود).
- التصنيفات/العلامات/الوحدات: عرض وإضافة.
- المخزون: عرض الأرصدة حسب المستودع، رصيد افتتاحي، تسوية مخزون.
- العملاء والموردون: بحث، صفحات، إضافة.
- لوحة تحكم بمؤشرات من بيانات حقيقية فقط (بدون أرقام وهمية).

## غير مُنفَّذ عمدًا في هذه المرحلة (موثَّق، وليس نسيانًا)

- تبديل اللغة إنجليزي/LTR (البنية RTL جاهزة عبر `dir="rtl"` على `<html>`؛
  التدويل الكامل i18n مؤجَّل).
- شاشات الجرد (Stock Count) والتحويل بين المستودعات - الـ API جاهز
  ومُختبَر بالكامل في الـbackend، الواجهة تُضاف لاحقًا.
- تعديل/حذف من الواجهة (متاح عبر الـAPI، الشاشات الحالية تركّز على العرض
  والإضافة لكل وحدة جديدة).
- معالج استيراد Excel.
