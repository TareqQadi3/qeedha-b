# Qeedha Accounting

برنامج محاسبي ونقاط بيع (POS) متكامل ومستقل للبقالات والسوبرماركت في
السعودية. **مستقل بالكامل عن مشروع "قيّدها"** — يعمل بكامل وظائفه بدون أي
تكامل خارجي، ويمكن لاحقًا ربطه اختياريًا بقيّدها أو بأي نظام آخر عبر
Integration Layer عامة. راجع `docs/QEEDHA_INTEGRATION.md` للتفاصيل.
